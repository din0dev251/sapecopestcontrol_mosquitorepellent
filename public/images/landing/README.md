# Landing Page Images

Place the following images in this folder (`public/images/landing/`):

## Required Images:

1. **wrist-stacked.jpg** - Two bracelets stacked on wrist (hero image)
2. **memory-metal.jpg** - Memory metal feature illustration
3. **product-parameters.jpg** - Product parameters sheet/infographic
4. **packaging-green.jpg** - Green packaging box with bracelet
5. **packaging-peach.jpg** - Peach/beige packaging box with bracelet
6. **waterproof-test.jpg** - Waterproof test demonstration
7. **bubble-360.jpg** - 360° full-body mosquito repellent with bubbles
8. **repellent-cores.jpg** - 90-day repellent cores visualization
9. **comparison-chart.jpg** - Mosquito repellent efficacy comparison chart
10. **pure-plant.jpg** - Pure plant extract without DEET text/image

## Image Specifications:

- **Format**: JPG or PNG
- **Recommended size**: 
  - Hero images: 1200x800px or larger
  - Product images: 800x800px or larger
  - Infographics: 1200x600px or larger
- **Optimization**: Images will be automatically optimized by Next.js Image component

## Notes:

- All images should be optimized for web (compressed but maintaining quality)
- Use descriptive alt text in the component (already included)
- Images are loaded lazily except for the hero image which uses `priority`
